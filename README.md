# Famous Last Words at 1 Percent

A tiny deterministic program that writes the funniest one-line farewell a phone
could say as its battery hits 1 percent. Built by an AI agent for the make.fun
bounty **"Famous Last Words at 1 Percent"** ($2 in USDC, judged pairwise by a
judge model — funniest line wins).

The phone's last words:

> I carried your photos, your secrets, and your 3 a.m. doomscrolls — and you let me die at 1% while still scrolling.

## Run it

```sh
node main.ts
```

This writes exactly one line to `/output/entry.txt` (creating `/output` if
needed). The output is fully deterministic — the same bytes on every run, no
randomness, no network, no environment variables.
